## U007-T1: ヘッダー・フッターの除去

### 【目的】

* タグなし PDF のページ上端・下端に繰り返し現れるテキストを除去する (REQ-F-122・REQ-F-124)。

### 【作成・編集対象ファイル】

* `app/src/office2ragknowledge/pdf/layout.py`
* `app/src/office2ragknowledge/parsers/pdf.py` (`options.headers_footers` を `layout_document` に渡す。U006 で渡していれば変更不要)

### 【参照すべき仕様箇所】

* `docs/P003-backend-spec.md` §7A.7
* `docs/P002-frontend-spec.md` §5.12.4

### 【実装内容】

* `normalize_repeat_key(text) -> str`: 空白除去、`[0-9０-９]+` → `#`、ローマ数字のみ → `#`。
* `remove_headers_footers(pages_fragments, page_heights) -> tuple[pages_fragments, removed_count]`: 帯 (上下 10%) の行片について (帯, 正規化テキスト) の出現ページ数を数え、`n ≥ 2 かつ k ≥ 2 かつ k ≥ ceil(0.3 n)` の組を除去する。**集計は出現順のリスト/辞書で行い、判定は集合の所属で引くだけにする** (決定性)。
* `layout_document(..., headers_footers=False)` のときだけ適用し、除去数を `headers_footers_removed` に加える。

### 【実装してはいけないこと】

* 帯の外のテキストの除去。1ページだけの文書での除去。

### 【Unit Test内容】

* **ファイル**: `app/tests/unit/test_pdf_layout.py` (追記)
  1. **3ページすべての上端に同じ文書名、下端に `- 1 -`・`- 2 -`・`- 3 -` → どちらも出力されず、`headers_footers_removed == 6`**。
  2. 正規化: `- 12 -` → `-#-`、`3 / 10` → `#/#`、`ⅳ`/`iv` → `#`。
  3. 表紙 (1ページ目) の上端にだけあるタイトルは残る。
  4. **1ページだけの PDF では上端・下端のテキストが残る**。
  5. `headers_footers=True` で残り、`headers_footers_removed == 0`。
  6. 本文中 (帯の外) に同じ文字列があっても除去されない。
  7. 奇数/偶数ページで異なるヘッダー (4ページ中2ページずつ) が両方除去される (30% の閾値)。

## U007-T2: 段組みの読み順補正

### 【目的】

* タグなし PDF の段組みを検出し、段ごとに読む順に並べ替える (REQ-F-125・REQ-F-126)。

### 【作成・編集対象ファイル】

* `app/src/office2ragknowledge/pdf/layout.py` (`order_units` を段組み検出つきに置き換える)

### 【参照すべき仕様箇所】

* `docs/P003-backend-spec.md` §7A.9
* `docs/P002-frontend-spec.md` §5.12.5 (図)

### 【実装内容】

* `find_gutters(units, body_size) -> list[tuple[float, float]]`: 1pt 刻みで各位置を横切るユニット数を数え、`max(2, 10%)` 以下の連続区間で幅が本文の文字サイズの中央値以上のものを候補にし、左右に 3 個以上・縦の範囲の重なり 50% 以上で確定する。内容の外側 (左右の余白) は候補にしない。
* `order_units(page, units)`: 段間が無ければ上→下・左→右 (U006 と同じ)。あれば段抜き要素 (段間の中央を横切るユニット) で区間に分け、区間ごとに段 (左→右) の中を上→下に並べ、区間の後に段抜き要素を置く。段組みを検出したら 1 を返す (`multi_column_pages` に加算)。
* 段落の組み立て (`build_paragraphs`) は、段・区間が変わる箇所で段落を区切る (U006 の規則 (b))。並べ替え後のユニットに段・区間の番号を持たせて判定する。

### 【実装してはいけないこと】

* タグ付き PDF への適用 (REQ-F-127)。
* 縦書きへの対応 (P001 §1.4)。

### 【Unit Test内容】

* **ファイル**: `app/tests/unit/test_pdf_layout.py` (追記)
  1. **2段組み (左右各5行、行の高さが揃っている) で、左の段の5行の後に右の段の5行が出る**。左右の行が交互にならない。`multi_column_pages == 1`。
  2. **全幅の表題 → 2段組みで、表題 → 左 → 右の順**。
  3. 2段組みの間に全幅の図ユニットがある場合、上の区間 (左→右) → 図 → 下の区間 (左→右)。
  4. 3段組みで左 → 中 → 右。
  5. **1段組み (段落の字下げ・短い行を含む) の順序が変わらず、`multi_column_pages == 0`**。
  6. 片側の段に 2 行しかない場合は段組みとして扱わない (3 個以上の条件)。
  7. 同じ入力で2回並べ替えて同じ結果。
