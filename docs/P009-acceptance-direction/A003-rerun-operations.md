# 【テストID】A003 — 再実行と出力先の運用

## 【目的】

* **同一の出力先に対して2回目の実行を行ったときに、正しく振る舞うこと**を検証する (P006 §2.3 の観点 O-01・O-02)。
* 単体テスト・結合テストは各テストごとに新しい一時ディレクトリを使うため**常に初回実行になり、この観点を検出できない**。本テストが唯一の検出手段である。

## 【参照テスト計画】

* `docs/P006-test-plan.md` §2.3 (運用観点 O-01・O-02・O-03), §4.1 (A003 のみスイート単位の復元)
* `docs/P003-backend-spec.md` §3.1 (データストアを持たないこと、および本アプリ固有の再実行確認)
* `docs/P002-frontend-spec.md` §5.2 (出力ファイルごとの個別判定)

## 【対象モジュール】

* `writer.py` / `batch.py` / `cli/main.py`

## 【前提条件】全モジュールビルドが成功していること

## 【使用するテストデータ】

* Word 1件、PowerPoint 1件、**Excel 2件** (二重出力の個別判定を検証するため)。
* うち1件は画像を含む (`--images extract` 時の画像の既存判定用)。

## 【事前準備】

* **本テストのみ、スイート単位の一時ディレクトリを使う** (`tmp_path_factory`)。テスト関数の中で同じ出力先を2回使うため。
* ベースラインは「出力先ディレクトリが存在しない、または空である状態」(P006 §4.2)。テスト開始時にこの状態を作る。

## 【実行手順】

1. 出力先を空にして1回目の変換を実行し、生成されたファイルの一覧とタイムスタンプ・内容を記録する。
2. **同じ出力先に対して2回目の変換を `--on-exists skip` で実行**し、挙動を確認する。
3. 同じ出力先に対して `--on-exists overwrite` で実行し、挙動を確認する。
4. 同じ出力先に対して `--on-exists fail` で実行し、挙動を確認する。
5. **Excel の出力のうち `.table.md` だけを残して `.grid.md` を削除**し、`--on-exists skip` で再実行する (O-02)。
6. `--images extract` で2回実行し、画像の扱いを確認する。
