# 【テストID】T003 — WordとPowerPointの変換

## 【目的】

* Word と PowerPoint の変換について、**生成された Markdown 全体**をゴールデンファイルと比較し、構造が仕様どおりであることを検証する。

## 【参照テスト計画】

* `docs/P006-test-plan.md` §2.1 F-02, F-03, F-10, F-11、§6 (ゴールデンファイル方式)
* `docs/P002-frontend-spec.md` §5.9 (Word), §5.10 (PowerPoint), §5.11 (画像)

## 【対象モジュール】

* `parsers/word.py` / `parsers/powerpoint.py` / `render/markdown.py` / `render/frontmatter.py` / `convert.py` / `writer.py`

## 【前提条件】対象スプリントの全モジュールビルドが成功していること

* U004 の単体テストが合格していること。

## 【使用するテストデータ】

* `sample.docx` — 見出し1〜3、箇条書き (2階層)、番号付きリスト、表 (結合セルあり)、太字/斜体/取り消し線、ハイパーリンク、脚注、画像 (代替テキストあり/なし)
* `sample.pptx` — 3スライド (タイトルあり2枚・なし1枚)、箇条書き (2階層)、表、発表者ノート (あり2枚・なし1枚)、非表示スライド1枚

## 【事前準備】

* `tmp_path` に入力を生成し、出力先を用意する。
* ゴールデンファイル `tests/integration/golden/sample.docx.md` / `sample.pptx.md` を用意する。**ゴールデンファイルは仕様から人手で書き起こし、実装の出力をそのままコピーしない** (実装の誤りをそのまま承認しないため)。

## 【実行手順】

1. `sample.docx` を既定オプションで変換し、ゴールデンファイルと比較する。
2. `sample.pptx` を既定オプションで変換し、ゴールデンファイルと比較する。
3. オプション (`--headers-footers` / `--comments` / `--no-notes` / `--include-hidden` / `--images extract`) を個別に有効化して差分を確認する。

## 【実行コマンド】

* `pytest tests/integration/test_word_powerpoint.py -v`
