# 【テストID】T001 — Excel二重出力の連携

## 【目的】

* 利用者の要求①②③が、**パーサから2ファイルの書き出しまで通しで**成立することを検証する。
  * 要求①: 1シート内の複数の表が、空行・空列を境界に分割されて出力される
  * 要求②: 数式のキャッシュ値が無い場合に、数式そのものが出力され警告が出る
  * 要求③: 表計算モードと方眼紙モードの2ファイルが、判別なしに常に生成される
* 単体テストでは各層を独立に検証しているため、本テストでは**層をまたいだ連携**を検証する。

* `docs/P002-frontend-spec.md` §5.2 (ファイル名), §5.3 (front matter), §5.4 (表計算モード), §5.6 (方眼紙モード)
* `docs/P001-requirement.md` §7.3 (申請書の出力例), REQ-F-051〜068

## 【対象モジュール】

## 【前提条件】対象スプリントの全モジュールビルドが成功していること

* U001〜U005 の全単体テストが合格していること。
* `office2rag --version` が実行できること。

## 【使用するテストデータ】

* `tests/helpers/make_office.py` でコード生成する `.xlsx`。次の3種類を用意する。
  1. **`mixed.xlsx`** — 3シート構成。
     * シート `売上` : 正規の表 (A1:D5 にヘッダ+データ)。1領域のみ。
     * シート `複数表` : A1:C4 に表1、E1:G3 に表2 (D列が空)、A6:C8 に表3 (5行目が空)。**要求①の検証用**。
     * シート `申請書` : P001 §7.3 の方眼紙レイアウト (A1「休暇」B1「申請」C1「書」/ 2行目空 / A3「氏名」C3「山田」D3「太郎」/ A4「所属」C4「開発」D4「部」)。**要求③-2 の検証用**。
  2. **`formula_nocache.xlsx`** — openpyxl で数式を書き出したファイル (キャッシュ値なし)。**要求②の検証用**。
  3. **`formula_cached.xlsx`** — 上記に `inject_cached_values()` でキャッシュ値を注入したファイル。

## 【事前準備】

* `tmp_path` に入力ファイルを生成する (テスト1件ごとに隔離。P006 §4.1)。
* 出力先ディレクトリ `tmp_path/out` を用意する (存在しない状態から始める)。

## 【実行手順】

1. `mixed.xlsx` を既定オプション (`--excel-modes both`) で変換し、出力先に2ファイルが生成されることを確認する。
2. 生成された `mixed.table.md` の内容を検証する (表領域の分割、小見出し、結合セルの複製)。
3. 生成された `mixed.grid.md` の内容を検証する (セルの直結、空行、結合の非複製)。
4. 両ファイルの front matter を検証する (`output_mode`、共有フィールドの一致)。
5. `formula_nocache.xlsx` を変換し、数式の出力と警告を検証する。
6. `formula_cached.xlsx` を変換し、値が出力されることを検証する。
7. `--excel-modes table` / `grid` で片方のみが生成されることを確認する。
8. 同じ入力を2回変換し、`converted_at` を除いて出力が一致することを確認する。
