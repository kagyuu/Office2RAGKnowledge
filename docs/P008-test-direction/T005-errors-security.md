# 【テストID】T005 — 異常系とセキュリティ

## 【目的】

* 異常な入力に対して**プロセスがクラッシュせず、必ず意味のあるエラーとして終了する**ことを検証する (REQ-NF-004)。
* セキュリティ防御 (ZIP爆弾・XXE・パストラバーサル) が、基盤モジュール単体ではなく**パーサ経由の実際の変換フローでも**機能することを検証する。

## 【前提条件】全モジュールビルドが成功していること

* U001・U005 の単体テストが合格していること。

## 【使用するテストデータ】

* `tests/helpers/make_malicious.py` で**プログラム生成する**細工ファイル (リポジトリに置かない。P006 §3.1):
  * ZIP爆弾 (高圧縮率エントリを含む `.xlsx`)
  * パストラバーサル (`../../evil.xml` を含む `.docx`)
  * XXE (`<!ENTITY xxe SYSTEM "file:///etc/passwd">` を含む `document.xml` を持つ `.docx`)

  * 破損 ZIP (途中で切れたバイト列)
  * OLE 複合ファイル (パスワード保護を模したシグネチャ)
  * 空ファイル (0 バイト)
  * 拡張子のみ Office のテキストファイル
* 既知の秘密文字列 (例: `SECRET-CANARY-12345`) を本文に含む正常な `.xlsx` (ログの本文非出力の検証用)

## 【事前準備】

* `tmp_path` に細工ファイルを生成する。
* 書き込み不可ディレクトリのテストは、作成できない環境ではスキップする (`pytest.mark.skipif`)。

## 【実行手順】

1. 各細工ファイルを `convert` で処理し、送出される例外とエラーコード・終了コードを確認する。
2. バッチに細工ファイルと正常ファイルを混在させ、**正常ファイルが処理されること**を確認する。
3. 既知の秘密文字列を含むファイルを `--verbose` で変換し、ログに秘密文字列が現れないことを確認する。
4. XXE を含むファイルで、外部ファイルが読まれないことを確認する。
