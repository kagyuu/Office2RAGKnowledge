## 3. 失敗したテスト (Reviewer Loop へ引き継ぐ)

### 失敗1 — 設定ファイルの `[excel] modes` が CLI の既定値に上書きされる

| 項目 | 内容 |
| --- | --- |
| テスト | `tests/integration/test_cli_screens.py::test_config_file_and_cli_precedence` |
| 対象要求 | **REQ-F-098** (優先順位: コマンドライン引数 > 設定ファイル > 既定値) |
| 期待 | 設定ファイルに `[excel] modes = "table"` を書き、CLI で `--excel-modes` を指定しない場合、表計算モードのみが出力される |
| 実際 | 両モードが出力される (`b.grid.md` も生成された) |
| 原因 | `cli/options.py` の `build_config` が、CLI オプションの既定値 (`excel_modes="both"`) を「利用者が明示指定した値」と区別できていない。`replace(excel, modes=modes)` が無条件に実行され、**設定ファイルの値を常に上書きする**。同じ問題が `images` / `shape_style` / `on_exists` / `log_format` および真偽値フラグにも存在する |
| 設計との差異 | `docs/P003-backend-spec.md` §8.5 が「**CLI 層のオプション既定値を `None` とし、`None` でないものだけを設定ファイルの値に上書き適用する**」と明記していたが、実装がこれに従っていない |
| 影響 | **REQ-F-098 が満たされていない。** 設定ファイルの大半のキーが機能しない |
| 重大度 | 高 (要求未達) |

### 失敗2 — ディレクトリ探索でスキップした非対応ファイルがサマリに計上されない

| 項目 | 内容 |
| --- | --- |
| テスト | `tests/integration/test_cli_screens.py::test_exit_codes` |
| 対象要求 | **REQ-F-094** (結果サマリにスキップ件数を表示する)、P002 §9.3 |
| 期待 | `.doc` を含むディレクトリを変換したとき、サマリに `スキップ 1 件` と表示される |
| 実際 | `スキップ 0 件` と表示される (終了コード 0 自体は期待どおり) |
| 原因 | CLI が `resolve_targets` で対象を確定し、その**解決済みファイル一覧**を `convert_batch` に渡している。`convert_batch` は受け取った一覧に対して再度 `scan_inputs` を実行するが、そこには既に非対応ファイルが含まれていないため、**スキップ情報が失われる** |
| 影響 | 利用者が「対象外のファイルがあったこと」に気づけない。変換漏れの見落としにつながる |
| 重大度 | 中 |
