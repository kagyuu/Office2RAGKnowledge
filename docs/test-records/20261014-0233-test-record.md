### 4.1 この確認で見つかった開発時依存の不足と是正

* **症状**: 新規 venv の Python 3.11 で、暗号化 PDF を生成するテスト10件が `pypdf.errors.DependencyError` (AES には cryptography が要る) で失敗した。
* **原因**: 開発時依存を `pypdf` としていたが、pypdf の AES 暗号化には `cryptography` が必要である。P102〜P205 で使った venv には、P003 §1.4 のスパイクで導入した pdfminer.six の依存として `cryptography` が**たまたま入っていた**ため、失敗が隠れていた。**Python の版の問題ではなく、新規の環境ならどの版でも起きる**。
* **是正**: `app/pyproject.toml` の開発時依存を `pypdf[crypto]` に改めた (配布物の実行時依存には影響しない)。是正後、3.11・3.12 の**新規** venv でそれぞれ2回続けて全件合格した (上表)。
* アプリケーションコード・テストコードは変更していない。
