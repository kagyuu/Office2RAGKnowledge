## F002 — スキップ件数の欠落 (REQ-F-094)

| 項目 | 内容 |
| --- | --- |
| 症状 | 非対応形式のファイルを含むディレクトリを変換したとき、サマリのスキップ件数が 0 と表示されていた |
| 原因 | CLI が `resolve_targets` で対象を確定した際、スキップ情報を捨てていた。`convert_batch` は対応形式のみの一覧を受け取るため、スキップを再検出できなかった |

| 副作用の有無 | 無し。`convert_batch` の変更は既定値付きの引数追加であり**後方互換** (`docs/P204-impact-analysis.md` §3 で7項目を確認) |
